# fabric/

Carpeta conectada al workspace `oil-dev` por la integración de Git de Fabric (D4). Cada item del
workspace aparece acá como una carpeta `<nombre>.<tipo>/` con su definición, por ejemplo
`nb_silver.Notebook/`. La escribe Fabric al hacer commit desde el workspace; los cambios hechos a
mano se traen al workspace con "Update".
